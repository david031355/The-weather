# Weather App (מזג אוויר בזמן אמת)

פרויקט אפליקציית מזג אוויר מבוסס נתוני Open-Meteo API.

## מה הפרויקט כולל?
1. **קימפול APK אוטומטי ב-GitHub Actions**: בכל Push, שרתי GitHub בונים ומקמפלים אוטומטית קובץ `app-debug.apk` להורדה בלשונית ה-Actions!
2. **אירוח חי ב-GitHub Pages**: קובץ `index.html` מוכן לפריסה בחינם.
3. **פרויקט Android Studio**: ניתן לפתיחה ולעריכה מקומית.

## הוראות פקודות Git להעלאה:
```bash
git init
git add .
git commit -m "Initial commit: Weather App with GitHub Actions APK builder"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```
